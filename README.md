# ASSIGNMENT-2-DATA-CLEANING-AND-TRANSFORMATION
This assignment focuses on cleaning and transforming a product dataset using microsoft excel.The objective is to improve data quality consistency and readability for further analysis.
# Objectives
- Handling missing values in the price and category column
- Correct inconsistent product name and category spelling
- Identify and remove duplicate rows
- Split product id into manufacturing date and country code
- Merge brand name and product name into a new product brand column
- Apply appropriate number formating
- Use conditional formating to highlight important information
## Tasks Performed

1. Handling Missing Values

   Checked for missing values in the Price and Category columns and considered suitable methods to handle them.

2. Correcting Inconsistent Data

   Standardized product name capitalization and corrected spelling mistakes in the Category column.

3. Removing Duplicates

   Checked the dataset for duplicate rows based on all columns and removed exact duplicates if present

4. Splitting and Merging Data

   Split product ID into seperate components for manufaturing date and country code.Combined brand name and product name into a new product        brand      column

5. Number Formatting

   Formatted the Price column as currency and set the date display format where valid dates were available.

6. Conditional Formatting

   Applied data bars to the Price column and highlighted Electronics entries in the Category column.
